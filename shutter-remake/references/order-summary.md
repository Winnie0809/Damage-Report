# 订单汇总规则

## 1. 仅使用每日和全部

定位当前订单总表，只扫描「每日」「全部」两个分表。总表文件名可参考「全部订单总和-副本.xlsx」，以实际文件为准。

按完整NA订单号、RM订单号或`RM数字(NA原订单号)`查找。数字只用于辅助定位，必须同时核对订单前缀、客户及订单名称。忽略其他分表，即使允许表中找不到记录也不扩大来源。

优先匹配允许表中明确关联的重做记录；没有时，定位原订单并按用户授权规则生成重做名称和关联号。区分“读取已有重做”与“根据原订单生成名称”，在异常列或执行记录说明来源。

同一记录在两表重复出现只输出一次。冲突字段留空并注明两表行号与差异，共同可确认字段正常填写。不要将原订单多条材料明细认定为多次重做；无法唯一确定明细时保留单条处理记录、共同值及待复核说明。只有允许表明确显示多个独立重做日期/对象时，才允许同一输入订单多行。

输入每个订单至少保留一条处理记录，按用户顺序排列。找不到时保留输入订单号并写明“未找到对应订单”。

## 2. B/C/D生成规则

以下均为虚构格式示例，不是真实客户或订单：

| Customer Name | Order Name | 原订单号 |
|---|---|---|
| ABC | Example Customer | NA12345 |

输出必须为：

| B | C | D |
|---|---|---|
| ABC Remake | ABC - Example Customer Remake - RM12345 | RM12345(NA12345) |

- B：客户简称加空格`Remake`。
- C：`客户简称 - 原订单名 Remake - RM数字`，Remake位于订单名之后、RM号之前。
- D：`RM数字(NA原订单号)`，作为文本。只有原NA订单时，用户授权沿用其数字生成RM号；若允许表有明确的不同RM关联，以真实关联为准。
- 允许表已有完整、明确的重做名称时保留原文，避免重复增加客户前缀、Remake或RM号；格式缺失时按已确认字段整理。
- 新组合时，如果原Order Name本身已以同一个已确认客户简称及分隔符开头，直接沿用完整Order Name后接` Remake - RM数字`，不再次添加客户简称。
- **没有已有RM记录不构成B/C/D留空的理由。**原订单和必要名称可确认时按规则生成，并注明“名称/编号按规则生成，允许分表未找到已有重做记录”。这不是伪造源表记录，不能宣称该记录已存在。

### Customer Name为空

检查允许表的Order Name是否有明确的客户简称前缀。例如Order Name为`ABC - Team - Example Customer`时：

- B：`ABC Remake`。
- C：`ABC - Team - Example Customer Remake - RM12345`。
- D：`RM12345(NA12345)`。

客户简称取自已确认的结构前缀，C保留原Order Name，不再额外拼一次ABC。异常列注明“Customer Name为空，简称从Order Name明确前缀提取”。

不得仅因Customer Name空白而机械留空B；也不能把任意订单名的第一段猜为客户。如果前缀含义不明确，B留空并注明；C可用完整原Order Name拼接Remake和RM号，不插入未确认客户。缺少Order Name时不猜名字，记录异常。禁止从其他分表或旧结果补值。

## 3. 固定12列

| 列 | 表头 | 内容 |
|---|---|---|
| A | Date | 使用被提取记录的订单日期，DD/MM/YYYY |
| B | Customer Name-Remake | 按上述客户规则填写 |
| C | Customer Name-Order Name-RM Number-Remake | 按上述名称规则填写 |
| D | RM Order Number (Original Order Number) | 明确关联或按授权生成的关联号 |
| E | Blank | 数据完全空白 |
| F | 原字段名1 | 原始值直接复制 |
| G | 原字段名2 | 原始值直接复制 |
| H | 原字段名3 | 原始值直接复制 |
| I | 原字段名4 | 原始值直接复制 |
| J | Blank | 数据完全空白 |
| K | Exception | 仅记录实际异常/来源例外，正常留空 |
| L | OK Date | ok DD/MM/YYYY，执行日后的下一个工作日 |

先确认F-I实际映射。常见字段依次为`Color`、`Tilt Rod`、`Material`、`Material&Tilt Rod`，用真实表头命名。结构不同则核实，不能任选四列。原值不翻译、不汇总、不重新计算；源为空目标也为空。提取重做记录时不能用原订单覆盖重做记录中的空白。

日期缺失或无法识别时留空并说明。Excel日期序号应按工作簿日期系统转换，文本日期确认日月顺序，不用文件创建/修改时间代替。

以用户时区（未另指定则沿用会话时区）的实际执行当天计算OK日期，周一至周五为工作日，跳过周末；用户提供节假日安排时一并排除。不得沿用旧日期或脚本中的固定日期。

## 4. 保存与检查

另存到源总表所在目录，文件名`Remake Order Summary_YYYYMMDD.xlsx`，重名增加编号。一个工作表`Remake Order Summary`；表头加粗、自动筛选、边框、适当列宽和自动换行，数据区不合并。

逐项检查：

- 数据来源全在每日/全部，执行记录能定位到分表和行号。
- 恰好12列，E/J完全空白，输入顺序正确，无重复提取。
- B/C/D符合命名规则；有明确客户前缀时B不机械留空；无客户前缀时不猜测。
- F-I逐值对应所选原始记录，日期与OK日期正确。
- 原始文件及已有输出未修改；不把XML解析通过表述成已完成Office渲染检查。

报告输入、匹配、未找到、异常订单数；存在多条独立记录时另报输出行数。
